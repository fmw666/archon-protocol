# Skills

Skills are **horizontal reusable capabilities** triggered by keywords, file types, or explicit demand intent. Every skill declares a `description` frontmatter field that states its trigger.

| Skill | Triggers on |
|-------|-------------|
| [`archon-framework`](/source/skills/archon-framework) | First encounter with an Archon-governed project; modifying any archon file; extending Archon; user asks "what is Archon?" |
| [`archon-git-commit`](/source/skills/archon-git-commit) | Committing code; "commit" / "提交" keyword |
| [`archon-signs`](/source/skills/archon-signs) | Adding/removing/auditing a `signs.md` row; post-review `stats-pass` candidate |
| [`blink-dispatch`](/source/skills/blink-dispatch) | During archon-demand close-out, before launching any sub-agent |
| [`external-agent-patterns`](/source/skills/external-agent-patterns) | Reviewing an outside AI-agent framework / prompt / harness |
