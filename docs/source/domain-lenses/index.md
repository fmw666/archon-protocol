# Domain Lenses

Pre-Verdict lens index used at the **Decision Gate**. Before routing any non-trivial demand, Archon selects the matching lens so the research phase converges on the right set of tools and reasoning frames.

| File | Purpose |
|------|---------|
| [`registry.yaml`](/source/domain-lenses/registry) | Lens index — maps domain signals to lens IDs |
| [`lenses/dev.md`](/source/domain-lenses/dev) | Dev lens: implementation-path · blast-radius · validation-plan |
| [`lenses/design.md`](/source/domain-lenses/design) | Design lens: palette-boundary · layout-reference · component-pattern · interaction-state · visual-constraint · critique-audit-loop |
| [`lenses/platform.md`](/source/domain-lenses/platform) | Platform lens: platform-boundary |
| [`lenses/ecosystem.md`](/source/domain-lenses/ecosystem) | Ecosystem lens: starter-catalog · evidence-gate · adoption-path |
| [`lenses/capability.md`](/source/domain-lenses/capability) | Capability lens: need-map · practice-selector · adoption-plan |
